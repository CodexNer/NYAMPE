Petunjuk Pengisian Aset Gambar NYAMPE
=======================================

Anda dapat meletakkan file gambar Anda di folder ini:
1. hero-banner.jpg  -> Gambar latar belakang hero section (rekomendasi: foto wanita traveler dengan pemandangan kota, ~1600x900px).
2. avatar.jpg       -> Foto profil di pojok kanan navbar (rekomendasi: foto profil lingkaran, ~200x200px).
3. logo.png / .svg  -> (Opsional) Logo kustom jika tidak menggunakan logo teks SVG bawaan.

Saat ini telah disiapkan fallback otomatis (jika file lokal belum dimasukkan, tampilan web tetap rapi dengan gambar contoh dan teks alt yang sesuai).
